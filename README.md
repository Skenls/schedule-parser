# Telegram Bot для парсинга расписания

Telegram-бот для автоматического отслеживания расписания учебной группы из канала колледжа с распознаванием фотографий через Google Gemini API.

## Возможности

- 🔍 **Мониторинг канала**: автоматический перехват новых публикаций с расписанием через Telethon (UserBot).
- 🧠 **Распознавание через Gemini**: извлечение даты, предметов, подгрупп, преподавателей и кабинетов с фото листа расписания.
- ⏰ **Утренний чекер**: плановая синхронизация расписания в 06:00 утра.
- 🔔 **Уведомления**: отправка напоминаний о следующей паре и кабинете за 15 минут до перемены с учетом выбранной подгруппы.
- ⚡ **Команды бота**:
  - `/start` — выбор подгруппы (1, 2 или вся группа).
  - `/today` — просмотр расписания на сегодня для своей подгруппы.
  - `/parse` — ручной запуск парсинга расписания из канала (только администраторы).
  - `/test` — тестовое уведомление (только администраторы).

## Установка и настройка

1. Скопируйте шаблон конфигурации:
   ```bash
   cp config.example.py config.py
   ```
2. Заполните `config.py`:
   - `GEMINI_API_KEY`: API ключ из [Google AI Studio](https://aistudio.google.com/).
   - `BOT_TOKEN`: токен бота от [@BotFather](https://t.me/BotFather).
   - `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`: данные приложения с [my.telegram.org](https://my.telegram.org).
   - `CHANNEL_USERNAME` / `CHANNEL_TARGET`: ID или юзернейм канала с расписанием.
   - `TARGET_GROUP`: название вашей группы (например, `"11П"`).
   - `TIMEZONE`: часовой пояс (например, `"Europe/Minsk"`).
   - `ADMIN_IDS`: список Telegram ID администраторов (например, `[123456789]`), которым разрешены команды `/parse` и `/test`.

## Запуск через Docker Compose

```bash
docker compose up -d --build
```

Просмотр логов:
```bash
docker compose logs -f
```
